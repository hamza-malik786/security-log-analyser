Security Log Analyser

Project Overview:

This is my first cybersecurity Python project... Its a simple security log analyser designed to identify suspicious login activity.

Features:

1. Reads security log entries.
2. Identifies failed login attempts.
3. Counts failed login attempts for each IP address.
4. Flags suspicious IP addresses with 3 or more failed login attempts.
5. Displays a security analysis report.

Technologies Used:

1. Python 3
2. Dictionaries
3. Loops
4. Conditional statements
5. File handling

How It Works:

The program analyses login records and tracks failed login attempts associated with each IP address.
If an IP address has 3 or more failed login attempts, the program identifies it as suspicious.
